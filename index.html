Git / hverdagsflyt

Hold orden.
Jobb fritt.

De viktigste Git-kommandoene samlet på ett sted. Finn kommandoen du trenger, forstå hva den gjør, og kom deg videre.

01

Oppsett

Gjøres én gang på maskinen din.

git config --global user.name "Navn"

Setter navnet som vises på commits.

git config --global user.email "epost@eksempel.no"

Knytter e-postadressen din til commits.

02

Start et prosjekt

git init

Starter versjonskontroll i mappen du står i.

git clone <url>

Laster ned en kopi av et eksisterende repository.

03

Se hva som skjer

git status

Viser endrede, nye og staged filer. Kommandoen du bruker aller mest.

git log --oneline

Viser commit-historikken, én kort linje per commit.

git diff

Viser nøyaktig hva som er endret, linje for linje.

04

Lagre endringer

add = gjør klar. commit = lagre lokalt.

git add <filnavn>

Legger en spesifikk fil i staging area.

git add .

Legger alle endrede filer i staging area.

git commit -m "melding"

Lagrer et øyeblikksbilde med en beskrivende melding.

05

Jobb med GitHub

git push

Sender lokale commits til det eksterne repositoryet.

git pull

Henter og slår sammen nye endringer.

git fetch

Henter endringer uten å slå dem sammen automatisk.

git remote -v

Viser hvilke eksterne repositories du er koblet til.

06

Branching

Jobb med flere versjoner samtidig uten å røre det som fungerer.

git branch

Viser alle branches og hvilken du står på.

git switch -c <navn>

Lager en ny branch og bytter til den.

git switch <navn>

Bytter til en eksisterende branch.

git merge <navn>

Slår en annen branch inn i den du står på.

07

Angre ting

git restore <filnavn>

Forkaster lokale endringer som ikke er staged.

git restore --staged <filnavn>

Angrer en git add, men beholder filendringene.

git revert <commit>

Lager en ny commit som reverserer en tidligere.

08

Tre vanlige situasjoner

Jeg vil lagre endringene på GitHub

git add .
git commit -m "Ny funksjon"
git push

Jeg vil hente siste versjon

git pull

Jeg vil starte en ny funksjon

git switch -c ny-funksjon
Ingen treff. Prøv for eksempel «branch» eller «commit».
